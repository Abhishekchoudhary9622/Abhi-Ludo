# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Abhi Ludo**, please help us protect the community by reporting it privately:

1. **Do not create a public issue** on GitHub.
2. Please contact Abhishek Choudhary directly through GitHub or open a private security advisory on the repository: [https://github.com/Abhishekchoudhary9622/Abhi-Ludo/security/advisories](https://github.com/Abhishekchoudhary9622/Abhi-Ludo/security/advisories).
3. Include details of the vulnerability, steps to reproduce, and any relevant logs or proofs-of-concept.

We will acknowledge receipt of your report within 48 hours and work with you on resolving the issue promptly before public disclosure.
